您的列表和笔记保存在您的设备上。MapGuide 不设账户、不投放广告，也不使用分析 SDK。地图和导航功能可能会向您选择的服务提供商发送查询和路线信息。

1. 发布者与联系方式

MapGuide 由位于波兰的 Konrad Witkowski 发布。如有隐私问题，或希望就您发送给我们的信息提出请求，请联系 witkompapp@gmail.com。

2. 保存在设备上的信息

MapGuide 在本地保存您的收藏集合、已保存的地点、自定义名称、笔记、标签、坐标、Apple 地点标识符、行程历史记录和偏好设置。未完成的导入也可能保存为本地草稿。我们没有运营用于接收这些数据副本的 MapGuide 服务器。

应用的数据目录使用 iOS 文件保护，并且不包含在设备自动备份中。这属于操作系统提供的保护，并不代表 SQLite 数据库经过了单独加密。如果您想保留计划，请在删除应用前导出备份。

3. 位置与地图服务

当您选择将当前位置用作行程起点，或将其保存为地点时，MapGuide 会请求在使用应用期间访问位置。应用不会在后台跟踪您的位置。您可以在 iOS“设置”中管理权限，也可以手动输入地点。

搜索地点、显示地图、根据 Apple 地点标识符查找地点以及比较路线均使用 Apple 的 MapKit 服务。相关查询、区域和路线点会发送给 Apple；公共交通时间估算还可能包含计划出发时间。请参阅 Apple 地图与隐私。

为进行中的行程获取的坐标可能会缓存在设备上，直到您明确结束或删除该行程。这些临时坐标不包含在导出的备份中。在 Apple 地图或 Google 地图中打开导航或地点信息时，必要的地点或路线信息会发送给相应服务。请参阅 Google 隐私权政策。

4. 导出、导入与 AI 助手

导出或共享由您主动发起。备份文件可能包含私人笔记和坐标。您选择的目标服务（例如文件服务提供商或即时通信应用）会按照其自身条款处理该文件。共享结束后，临时导出文件会被删除。

可选的 AI 规划功能会根据您输入的规划详情在本地生成提示词，并将其复制到剪贴板。您自行决定是否将其粘贴到外部助手中。MapGuide 不会自动向 AI 提供商发送已保存的集合或笔记。导入的建议在您确认保存前会供您检查；匹配建议中的地点会使用 Apple 地图。

5. 保留与删除

本地列表、地点、笔记和行程历史记录会保留到您在应用中删除它们或删除应用为止。您可以在“设置”中删除未使用的地点，并在导入工具中丢弃导入草稿。结束或删除行程会清除该行程由服务提供商提供的临时坐标。导出的文件是独立副本，请从您保存它们的位置或服务中另行删除。

我们无法访问、导出或删除仅存在于您设备上的数据。如果您在使用应用的数据管理功能时需要帮助，请联系我们。

6. 支持与测试版反馈

当您向我们发送电子邮件时，我们会收到您的邮箱地址、邮件内容以及您选择发送的附件。我们使用这些信息回复您的请求并调查问题。除非解释请求确有必要，请勿发送敏感笔记或精确位置。您可以联系我们，要求访问、更正或删除与支持团队的往来邮件。

应用不包含广告、跟踪、分析或第三方崩溃报告 SDK。在通过 TestFlight 进行测试期间，Apple 会自动收集崩溃日志和使用信息，并将它们与您提交的反馈一起分享给我们。根据您加入测试的方式，其中可能包含您的姓名和邮箱地址。我们使用这些信息调查问题并改进 MapGuide。请参阅 TestFlight 与隐私。

7. 本网站

本静态网站托管在 GitHub Pages 上。我们不添加分析、广告、Cookie 或跟踪脚本。图片和样式均由本网站提供，不加载外部字体或嵌入式地图。

GitHub 出于安全目的记录访问者的 IP 地址。请参阅 GitHub Pages 数据收集说明和 GitHub 隐私声明。外部服务有各自的隐私处理规则。

8. 本政策的变更

本政策可能随 MapGuide 的变化而更新。上方日期用于标识当前版本。数据处理方式的重大变更将在此说明。
